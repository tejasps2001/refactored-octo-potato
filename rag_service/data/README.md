# Lecture Data Directory

Place your lecture materials here for the RAG and ingestion pipelines:
- **Video/audio file** (e.g., `lecture.mp4` or `lecture.mp3`)
- **PDF slides/notes** (e.g., `slides.pdf`)
- **Text notes** (e.g., `notes.txt`)

These files will be automatically loaded, transcribed, and indexed into the local vector database on startup.

*Note: The actual lecture files placed in this directory are ignored by Git and will not be committed.*
